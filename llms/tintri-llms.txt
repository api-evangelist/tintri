# Tintri

> Tintri (now part of DDN) builds intelligent, virtualization-aware enterprise storage and data-management infrastructure — the VMstore platform, Tintri Cloud Platform (TCP) and Cloud Engine (TCE), and Tintri Global Center (TGC). Every VMstore appliance and TGC instance exposes a versioned, session-authenticated REST API (v310) for automating VM- and virtual-disk-level provisioning, snapshots, replication, QoS, alerting, and per-VM analytics.

## API

- [Tintri VMstore REST API (v310) reference](https://tintri.github.io/tintri-rest-api/index.html): session-authenticated JSON REST API served on each VMstore/TGC appliance under /api/v310. Version v310.91 maps to TXOS 4.5 and TGC 4.1+.
